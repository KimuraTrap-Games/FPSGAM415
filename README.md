# FPSGAM415
Course: GAM 415 – Graphics Game Engine  
Developer: Scott Lee
Description: A first-person shooter prototype demonstrating Unreal Engine 5 gameplay systems.  

## Skills Demonstrated
- Game Engine Mastery  
- 3D Graphics  
- Game Physics  
- Problem Solving in Game Logic  

## Tools Used
Unreal Engine 5, C++, Visual Studio, GitHub  

## How to Run
1. Clone the repository  
2. Open the `.uproject` file in Unreal Engine 5  
3. Press Play to test the FPS gameplay
